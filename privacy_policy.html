Privacy Policy

DevReload Chrome Extension — Last updated: May 2026

1. Overview

DevReload ("the Extension") is a developer utility that watches local files for changes and reloads the active browser tab. This policy explains what data the Extension accesses, how it uses that data, and what it does not do.

2. Data We Access

  • Local file system (via File System Access API): When you click "Pick Folder", the browser asks for your explicit permission to read a folder you choose. The Extension reads file metadata (lastModified timestamps) and, when CSS-only reload is active, the text content of changed CSS files. No other files are read.
  • Active browser tab: The Extension reloads (or injects CSS into) the currently active tab when a file change is detected. It reads the tab's ID for this purpose only.
  • Extension settings: Your preferences (polling interval, file extensions filter, CSS-only mode, enabled state, and the last few detected-change entries) are stored locally in chrome.storage.local on your device.
  • Directory handle: A reference to your chosen folder (a FileSystemDirectoryHandle) is stored in IndexedDB on your device so the Extension can resume watching after a browser restart. This handle cannot be used to access your files by any other origin.

3. Data We Do NOT Collect

  • We do not transmit any data to external servers or third parties.
  • We do not store, log, or read the contents of your files, except the CSS text content temporarily used for in-page injection (never stored).
  • We do not collect analytics, usage metrics, or crash reports.
  • We do not use cookies or any tracking technology.

4. Permissions Explained

  • storage — saves your settings locally in chrome.storage.local.
  • tabs — reads the active tab ID in order to reload it.
  • activeTab — grants temporary access to the active tab when the extension is invoked.
  • scripting — injects updated CSS into the active tab (CSS-only reload mode only).

5. Third-Party Services

DevReload has no external dependencies and makes no network requests. All functionality works entirely offline.

6. Children's Privacy

DevReload is a developer tool not directed at children. We do not knowingly collect any personal information from anyone.

7. Changes to This Policy

If this policy changes, the updated version will be published at the same URL with a revised "Last updated" date.

8. Contact

Questions about this privacy policy? Please open an issue in the project repository or contact the developer at the address listed on the Chrome Web Store listing page.

DevReload is an open-source project. No data leaves your device.
